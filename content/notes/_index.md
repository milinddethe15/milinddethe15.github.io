This section mirrors directories in the `notes-hub` submodule. Run `npm run sync:notes` whenever you add or rename a folder so the site generates a dedicated page for it. If you add Excalidraw boards (`*.excalidraw`), export fresh SVGs for the site with `npm run render:excalidraw` or simply execute `npm run prepare:notes` to do both steps in one go.
